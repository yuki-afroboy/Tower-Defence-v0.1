# Last Fortress Defense

スマートフォンのブラウザで遊べる、2Dタワーディフェンスゲームです。
全15Wave。最後のWaveのボスを倒せばクリアです。

インストール不要・ログイン不要。**スマホのブラウザでURLを開くだけ**で遊べます（→「1. 遊び方」）。
ホーム画面に追加すればアプリのように起動でき、オフラインでも動きます。

---

## 1. 遊び方

### スマホのブラウザで開くだけ（おすすめ）

GitHub Pages を有効にすると、次のURLで遊べるようになります。

```
https://yuki-afroboy.github.io/Tower-Defence-v0.1/
```

**最初の1回だけ、GitHubで設定が必要です（スマホからできます）**

1. スマホのブラウザで https://github.com/yuki-afroboy/Tower-Defence-v0.1 を開く
2. 上部（または「…」メニュー）の **Settings**（設定）をタップ
3. 左メニュー（または下にスクロール）の **Pages** をタップ
4. **Build and deployment** の欄で
   - Source … `Deploy from a branch`
   - Branch … **`claude/tower-defense-game-uf2axz`** を選び、フォルダは **`/ (root)`**
   - **Save** をタップ
5. 1〜2分待ってから上のURLを開く（最初はまだ表示されないことがあります）

#### ホーム画面に追加すると、もっと遊びやすくなります

- **iPhone**：Safariでゲームを開く → 下の共有ボタン → 「ホーム画面に追加」
- **Android**：Chromeでゲームを開く → 右上の「⋮」 → 「ホーム画面に追加」

こうするとアイコンから起動でき、URLバーのない全画面表示になります。
さらに **一度開いたあとは電波がなくても遊べます**（オフライン対応済み）。

### 通信なしで遊びたいとき（1ファイル版）

`dist/LastFortressDefense.html` は、この1ファイルだけでゲームが動きます
（CSS・JavaScript・アイコンを全部埋め込み済み・約180KB）。
パソコンにダウンロードして開く場合や、他の人に丸ごと渡したいときに便利です。

※ iPhoneの「ファイル」アプリから直接開くと、プレビュー表示になって
動かないことがあります。その場合は上のURLから遊んでください。

### パソコンで遊ぶ場合

`index.html` をダブルクリックするだけです。

```bash
npm start          # http://localhost:8000 でも確認できます
```

### 操作（すべてタップだけ）

| やりたいこと | 操作 |
|---|---|
| タワーを置く | 下のタワーカードを選ぶ → 光っているマスをタップ |
| 置くのをやめる | 「キャンセル」を押す |
| タワーを強化・売却 | 置いたタワーをタップ → 「強化」か「売却」 |
| 敵を出す | 「WAVE ○ を開始」を押す |
| 早く進める | 「×1」を押して「×2」にする |
| 一時停止 | 「❚❚」を押す |
| ☄メテオを撃つ | ボタンを押す → 落としたい場所をタップ |
| ❄氷結を使う | ボタンを押す（即発動） |

Waveの最中に「次を呼ぶ」を押すと、**ボーナスゴールドをもらって次のWaveを前倒し**できます。
上級者向けの稼ぎ方です。

## 2. 基本ルール

- 敵は左上の **START** から出て、道を通って下の **BASE**（拠点）へ向かいます
- 敵が拠点に着くと拠点HPが減ります。**0になるとゲームオーバー**
- 敵を倒すとゴールドがもらえます
- ゴールドでタワーを置く・強化する
- **Wave15のボスを倒せばVICTORY**

タワーは道の上には置けません。緑に光ったマスだけに置けます。

---

## 3. アクティブスキル（Wave中に使える必殺技）

ゴールドは不要で、**時間が経つと自動で回復**します。ボタンの色が明るくなったら使えます。

| スキル | 効果 | 再使用まで |
|---|---|---|
| **☄ メテオ** | 狙った場所に隕石。**装甲を無視した範囲ダメージ**＋少し減速 | 30秒 |
| **❄ 氷結** | 画面上の**すべての敵**を2.5秒間おおきく減速 | 36秒 |

Waveをただ眺めるのではなく、
「敵が固まったところにメテオ」「漏れそうな瞬間に氷結」といった判断が勝敗を分けます。

シミュレーションでは、**同じ編成でもスキルを使うと平均残HPが約9→20**まで改善します。
ただしスキルだけでは勝てないよう調整してあり、**1種類のタワーだけの編成は
スキルを完璧に使っても15Waveをクリアできません**。

## 4. タワー（4種類・各4段階）

| タワー | 値段 | 特徴 | 得意 | 苦手 |
|---|---|---|---|---|
| **Archer** | 60 | 安くて連射が速い。単体攻撃 | 序盤全般・数の多い敵 | 装甲の厚いTank |
| **Cannon** | 120 | 遅いが高威力の**範囲攻撃** | Swarmなどの集団 | すばやいFast（弾が遅くて避けられる） |
| **Ice** | 90 | 射程内の敵を**まとめて減速** | 他のタワーの補助 | 単体ではほぼ倒せない |
| **Sniper** | 220 | 長射程・高火力・**装甲を無視** | Tank・ボス | 近すぎる敵は撃てない／Swarmには効率が悪い |

各タワーは **Lv1 → Lv4**（3回強化）まで育てられます。土台の下の白い点がレベルです。

### Lv4は「2つの進化先」から選びます

最後の強化だけは**2択**です。選ぶと性能も見た目も変わります（金枠 or 水色枠）。

| タワー | 進化A | 進化B |
|---|---|---|
| Archer | **連射**：手数で押す | **貫通**：装甲を無視。Tank対策 |
| Cannon | **重砲**：一撃が重く範囲も広い | **焼夷**：着弾後も燃え続ける（装甲無視） |
| Ice | **絶対零度**：減速特化 | **氷嵐**：広範囲に大ダメージ |
| Sniper | **必中**：一撃特化。ボス用 | **速射**：手数が約2倍 |

同じ編成でも進化の選び方で戦い方が変わります。

売却すると、それまでに使ったゴールドの **60%** が戻ってきます。

### 組み合わせのコツ

- **Ice + Cannon**：キャノンの弾は「敵が今いる場所」に向かって飛ぶので、足の速い敵には当たりません。
  アイスで減速させると当たるようになります
- **Sniper はボス用**：装甲を無視できるので、装甲22のボスに対しては一番効率がいい
- **Archer は序盤の主力**：安いので早く数をそろえられる。ただし装甲持ちのTankにはほとんど効かない

同じタワーばかり並べても後半は勝てないようになっています。

## 5. 敵（5種類）

| 敵 | 特徴 |
|---|---|
| **Normal**（赤い丸） | 基本の敵 |
| **Fast**（黄色い矢) | HPは低いが非常に速い |
| **Tank**（灰色の四角） | HPが高く**装甲12**。並のタワーではほとんど削れない |
| **Swarm**（緑のひし形） | 弱いが大量に出てくる |
| **BOSS**（ピンクの星） | Wave15に登場。HP約12,800、装甲22。倒せば勝ち |

---

## 6. Wave構成（全15）

| Wave | 内容 |
|---|---|
| 1〜3 | Normalのみ。練習 |
| 4〜6 | Fastが登場。数も増える |
| 7〜9 | Tankが登場。装甲対策が必要になる |
| 10〜12 | Swarmの大群、Tank+Swarmの複合 |
| 13〜14 | Tank+Fast+Normal / Tank+Swarm+Fast の高難易度 |
| 15 | **BOSS** + Tank×4 + Swarm×26 |

### Wave特性（一部のWaveにだけ付く特殊条件）

該当Waveでは画面上部にバッジが出て、敵に色付きのリングが付きます。

| 特性 | 効果 | 対策 |
|---|---|---|
| 🛡 **重装**（Wave 8, 13） | 敵の装甲+6 | 貫通・スナイパー・焼夷・メテオ |
| 💨 **疾走**（Wave 5, 12） | 移動速度+35% | アイスで減速、氷結 |
| ✚ **再生**（Wave 10, 14） | 毎秒HPの2%を回復 | 一気に削る（重砲・メテオ） |

## 7. ファイル構成

```
index.html          ページ本体（ここを開けば遊べる）
.nojekyll           GitHub Pages でファイルをそのまま配信するための印
manifest.webmanifest ホーム画面に追加するための設定
sw.js               オフラインで遊ぶための仕組み（Service Worker）
assets/             ホーム画面用アイコン
dist/               1ファイル完結版（スマホに保存して遊ぶ用）
css/style.css       見た目（スマホ縦画面用）
src/
  config.js         ゲームの数値すべて（バランス調整はここ）
  engine.js         ゲームのルール・計算（画面には触らない）
  renderer.js       Canvasへの描画
  sfx.js            効果音（音声ファイル不要・WebAudioで合成）
  ui.js             ボタンやタッチ操作と、ゲームループ
tests/
  engine.test.mjs   ルールの自動テスト
  balance.test.mjs  バランスの自動テスト
  browser.test.mjs  実際のブラウザ(390x844)での操作テスト
tools/
  balance-sim.mjs   いろいろな戦略で15Waveを自動プレイして強さを比べる
  winrate.mjs       複数の乱数で勝率を測る（バランス調整の主役）
  playtest.mjs      実際のゲームループのままUI操作で数Wave遊ぶ確認用
  shot.mjs          スクリーンショット撮影
```

`engine.js` が画面に一切触らない作りなので、**ブラウザなしでゲームを高速に何百回もシミュレーション**でき、
バランス調整と自動テストがしやすくなっています。

## 8. 開発用コマンド

```bash
npm install          # テスト用に playwright を入れる（遊ぶだけなら不要）

npm test             # ルールとバランスのテスト（数秒）
npm run test:browser # 実際のブラウザでの操作テスト
npm run test:all     # 全部

npm run balance      # 戦略ごとの強さを一覧表示（バランス調整用）
npm run balance:sk   # スキルを使うAI付きで同じ比較
npm run winrate      # 8種類の乱数で勝率を測る（調整はこれを見る）
npm run winrate:sk   # スキルあり版の勝率
npm run shot         # tests/screenshots/ に画面を保存
npm run build        # dist/LastFortressDefense.html（1ファイル版）を作り直す
npm run icons        # assets/ のアイコンを作り直す
```

`src/` や `css/` を編集したら、`npm run build` を実行して1ファイル版を作り直してください。

### バランスを変えたいとき

`src/config.js` の数字を変えるだけです。

- `TOWERS` … タワーの値段・攻撃力・射程など
- `ENEMIES` … 敵のHP・速さ・装甲・ゴールド
- `WAVES` … 各Waveの敵構成と `hpMul`（HP倍率）
- `BALANCE` … 開始ゴールド・拠点HP・売却率など

変えたら `npm run balance` を実行すると、
「理想的なプレイなら勝てるか」「1種類だけのタワーでは負けるか」を確認できます。
